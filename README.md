This repository holds the suite overview for the BCP-004 series of AMWA Best Common Practices, part of the family of [Networked Media Open Specifications](https://specs.amwa.tv/nmos) from the [Advanced Media Workflow Association](https://amwa.tv).

<!-- INTRO-START -->

### What does the suite do?

- The BCP-004 series defines how NMOS Senders and Receivers express parametric capabilities and constraints.
- It establishes how Controllers use those capabilities when evaluating possible connections and active constraints.

### Why does it matter?

- Controllers need to know whether a Sender and Receiver can interoperate before attempting a connection.
- A consistent capability model allows implementations to describe supported stream parameters without vendor-specific conventions.

### What are the recommendations?

- [BCP-004-01: NMOS Receiver Capabilities](https://specs.amwa.tv/bcp-004-01)
- [BCP-004-02: NMOS Sender Capabilities](https://specs.amwa.tv/bcp-004-02)
