## Introduction

The BCP-004 series defines how NMOS Senders and Receivers express parametric capabilities and constraints. It provides a consistent model for describing the stream parameters an endpoint can produce or consume and for evaluating compatibility before a connection is made.

The suite is divided into two complementary recommendations:

- [BCP-004-01: NMOS Receiver Capabilities](https://specs.amwa.tv/bcp-004-01) covers the capabilities and constraint sets expressed by Receivers.
- [BCP-004-02: NMOS Sender Capabilities](https://specs.amwa.tv/bcp-004-02) covers the capabilities and constraint sets expressed by Senders.

The recommendations use the NMOS Parameter Registers and the IS-04 `caps` attribute. They should be read alongside:

- [IS-04: NMOS Discovery and Registration](https://specs.amwa.tv/is-04/)
- [IS-05: NMOS Device Connection Management](https://specs.amwa.tv/is-05/)
- [IS-11: NMOS Network Media Configuration](https://specs.amwa.tv/is-11/)
- [NMOS Parameter Registers](https://specs.amwa.tv/nmos-parameter-registers/)
